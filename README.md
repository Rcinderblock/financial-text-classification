# Financial Text Classification

Классификация английских финансовых новостей: `negative`, `neutral`, `positive`.
Проект включает проверку данных, очистку текста, обучение, сравнение методов,
анализ ошибок и предсказания с сохранённой моделью.

## Данные

[Financial PhraseBank](https://huggingface.co/datasets/takala/financial_phrasebank),
часть `Sentences_AllAgree`: предложения, для которых все разметчики согласились
с тональностью. Исходный CSV с колонками `text` и `sentiment` включён в проект.
Из 2264 строк после удаления пяти дубликатов осталось 2259:
303 отрицательных, 1386 нейтральных и 570 положительных.
Источник, авторы и лицензия CC BY-NC-SA 3.0 указаны в [data/README.md](data/README.md).

## Установка и запуск

Нужен Python 3.12. Из папки проекта:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Готовая обученная модель находится в `models/`. Предсказание без переобучения:

```bash
python predict.py --text "The company's profit increased significantly."
python predict.py --text "Sales declined." --text "The company is based in Finland."
```

Вход функции `predict_sentiment()` — строка или непустой список строк.
Выход — список объектов с исходным `text`, числовым `label` и `sentiment`.
Пустые тексты и строки длиннее 20000 символов отклоняются.

```json
[{"text": "Sales declined.", "label": 0, "sentiment": "negative"}]
```

Для CSV с колонкой `text`:

```bash
python predict.py --input examples/new_texts.csv --output output/predictions.csv
```

Полное обучение и пересоздание отчётов:

```bash
python train.py
```

Другой размеченный CSV и отдельная папка результатов:

```bash
python train.py --input data/raw/financial_news.csv --output output/retrained
python predict.py --model output/retrained/models/best_model.joblib --text "Sales declined."
```

Для обучения принимаются `text`/`sentiment` или `headline`/`label`.
Метки: `negative=0`, `neutral=1`, `positive=2`; нужны все три класса.
Данные уже включены, доступ к сети для обучения не требуется.
Повторная загрузка фиксированной версии источника с проверкой SHA-256:

```bash
python load_data.py
```

## Обучение и результаты

Очищенные тексты разделяются на обучающие 80% (1807 строк) и тестовые 20%
(452 строки) с сохранением пропорций классов, `random_state=42`.
Совпадающие очищенные тексты не пересекают эти части.
Внутри обучающих 80% используются три одинаковых разбиения для сравнения моделей
и подбора параметров. Словарь и веса TF-IDF обучаются заново внутри каждого
разбиения. Победитель выбирается до вычисления тестовых метрик.

| Метод | Macro F1, проверка внутри обучающей части |
|---|---:|
| TF-IDF слов (1–2) + Logistic Regression | 0.7353 |
| TF-IDF слов (1–3) + Logistic Regression | 0.7294 |
| Logistic Regression с весами классов и подбором `C` | 0.8186 |
| LinearSVC с весами классов и подбором `C` | 0.8236 |
| TF-IDF слов и символов + LinearSVC | **0.8357** |

После выбора базовая и лучшая модели обучены на всех обучающих 80%.
Результат на одном отложенном тесте:

| Модель | Macro F1 | Accuracy |
|---|---:|---:|
| Базовая | 0.8273 | 0.8805 |
| Лучшая | **0.9135** | **0.9336** |

Прирост Macro F1: **8.62 процентного пункта**, или **10.42%** относительно
базовой модели. Добавление триграмм само по себе не улучшило результат.
Подробные результаты и параметры: [comparison.md](reports/comparison.md),
[cv_search.json](reports/cv_search.json), [metrics.json](reports/metrics.json).

## Обработка текста и сохранение

Очистка нормализует регистр и Unicode, удаляет HTML-теги и лишние пробелы,
сохраняет отрицания, числа, проценты и финансовые обозначения.
Пустые записи, дубликаты после очистки и тексты с конфликтными метками удаляются;
неизвестные метки вызывают ошибку.

В `models/best_model.joblib` сохранён весь `Pipeline`: очистка → признаки →
классификатор. Он принимает исходные строки и обеспечивает одинаковую обработку
при обучении и предсказании. `vectorizer.joblib` содержит отдельно сохранённые
обученные преобразователи признаков. Версии библиотек, параметры, метрики и
контрольные суммы находятся в `models/metadata.json`.
Лучшая модель LinearSVC не выдаёт вероятности; функция возвращает метку класса.
При использовании модели с `predict_proba` дополнительно возвращаются вероятности.

## Ограничения

Модель рассчитана на английские предложения о финансах. Оценка получена на
одном случайном разбиении части корпуса с полным согласием разметчиков;
она не проверяет перенос на другие компании, периоды и источники.
Словесные и символьные признаки плохо описывают сложные сравнения,
отрицания и смешанную тональность. Пять демонстраций иллюстрируют использование;
метрики качества считаются по отложенной выборке.

Основные файлы: `load_data.py` — данные, `preprocess.py` — очистка,
`eda.py` — первичный анализ, `train_baseline.py` и `train_improved.py` — модели,
`train.py` — полный цикл, `error_analysis.py` — ошибки, `predict.py` — предсказания.
